# Contributing

This is a scientific archive. Contributions must preserve the distinction
between observation, inference and speculation.

Before adding a result:

1. Define the hypothesis and the discriminating prediction.
2. Record model/version, timestamp, request design, repetitions and limits.
3. Preserve raw output or a verifiable aggregate receipt.
4. State alternative explanations and known confounders.
5. Update the evidence matrix and hypothesis tracker together.

Do not commit API keys, local caches, model weights, private state text or
unreviewed production data. Accuracy improvements alone are not sufficient;
the project prioritizes information gain about decision architecture.
